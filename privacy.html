Privacy policy

Last updated: 7 October 2026

What this application does

This OAuth client is used by a personal, self-hosted rclone installation to read and write files in the Google Drive account of its owner. It requests the https://www.googleapis.com/auth/drive scope so that it can list, upload, download, and delete files that the owner has asked it to synchronise.

What data is collected

None. The application has no backend server, no database, and no analytics. It does not collect, log, or transmit any personal data to the author or to any third party.

Where data is stored

OAuth tokens issued by Google are stored only in a local configuration file on the owner's own computer. They are never uploaded anywhere.

How data is used

File data is transferred directly between the owner's computer and Google Drive. It is used solely to perform the synchronisation operations the owner requests. No file content is read for any other purpose.

Third-party sharing

No data is shared with anyone. The only external service contacted is the Google Drive API itself.

Data retention and deletion

Because no data is retained by this application, there is nothing to delete on its side. Access can be revoked at any time from the Google Account permissions page, and local tokens can be removed by deleting the rclone configuration file.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
